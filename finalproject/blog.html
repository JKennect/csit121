Lessons learned While Building a Website

Published May 2026 by J

Approved by Alan Smithee

While doing this project, I learned that you shouldn't really prioritize making lore for a website over actually making a website. While the HTML is fine, the CSS page looks like a mess. There are too many redundant classes that do the same thing. The CSS and HTML for topnav came straight form lab 08. Some things do not resize properly. Even though the CSS looks messy, the site itself does not look too bad. I think prospective customers will have a laugh at some of the content on the site. Overall, I say I did a good job. The most tedious part of this project ways coming up with lore for PixelForge Studios. Although it was tedious, It was kind of fun. I spent over a day trying to generate content to go on the site. It also took me way too long to get the favicon working correctly

While testing the site, I noticed that things really stretch out on an ultrawide monitor. monitors like mine are not that common, so websites tend to have lots of empty space left over. Safari on Mac would not display the favicon from the html file. Chrome displayed it fine. Trying to view the file from the original file on an iphone strips out the CSS.

In this class, I learned about how website work then I did previously. The site that I made in another class was barebones compared to this final project site. Learning how to use an external stylesheet saves a lot of time over copying and pasting code each time inline. Flexboxes helped to make sites not look like reading a newspaper I would say that I have made a big improvement over the last few months. I think that the class was fun. We had a lot of freedom to customize sites.
